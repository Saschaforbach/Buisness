What leaves your plant. And what does not.

We document which data is transmitted, over which port, in which direction and where it is stored. Your IT can then decide in ten minutes instead of asking questions for two weeks.

Data scope

Your know-how stays in-house.

The edge box reads condition variables, not production content. What makes up your competitive advantage, it never sees.

Stays with you

  • NC programs and tool offsets
  • Drawings, CAD and CAM data
  • Workpiece geometry and part dimensions
  • Order, customer and costing data
  • Operator and shift data
  • Raw vibration signals

Transmitted encrypted

  • Calculated vibration features of the spindle
  • Speed and load values from the CNC control
  • Machine status and CNC control alarms
  • Timestamps and machine identifier

The box calculates the features on site and transmits only the result. No production content can be reconstructed from these values.

Protection against intervention

Read-only. Four independent safeguards.

The most common question from maintenance teams is: can the device change settings on my machine? No. Four mutually independent safeguards make sure of that.

  • A
    No write functionThe software contains no code that writes to a CNC control. What does not exist cannot be triggered.
  • B
    Upstream blockA dedicated protective layer blocks any request that would change something before it reaches the CNC control.
  • C
    Automated checksWith every change to the software, automated tests verify that no write path has been introduced.
  • D
    Read-only user on the CNC controlA dedicated user with read rights only, for SINUMERIK for example only SinuReadAll and AlarmRead.

No further rules are needed. The box cannot be reached from outside; it accepts no inbound connections.
